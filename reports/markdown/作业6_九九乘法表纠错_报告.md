# 汇编语言 作业 6 · 九九乘法表纠错

> 题目：**二·九九乘法表纠错**
>
> 环境：DOSBox 0.74-3 + MASM 5.10 / LINK 3.64；C 部分使用 Turbo C++ 3.0。
>
> 仓库：<https://github.com/Rayrayray35/assembly-homework>

## 一、题目要求

1. 检查 `9×9` 乘法表内的数据是否正确，把不正确的位置确定下来并显示在屏幕上。
2. 用 `CALL` / `RET` 实现过程调用；过程中需要使用主过程的寄存器资源，掌握调用前后的保存与恢复。
3. 复习双重循环的实现。
4. 注意数据段的寻址方式。
5. 用 C 语言实现后查看反汇编代码并加注释；观察把数据分别定义为全局和局部的区别。

题面给出的数据段：

```asm
data segment
table db 7,2,3,4,5,6,7,8,9
      db 2,4,7,8,10,12,14,16,18
      db 3,6,9,12,15,18,21,24,27
      db 4,8,12,16,7,24,28,32,36
      db 5,10,15,20,25,30,35,40,45
      db 6,12,18,24,30,7,42,48,54
      db 7,14,21,28,35,42,49,56,63
      db 8,16,24,32,40,48,56,7,72
      db 9,18,27,36,45,54,63,72,81
data ends
```

表按**行优先**存放：`table[(row-1)*9 + (col-1)]` 就是第 `row` 行第 `col` 列的值。

## 二、运行结果

在 DOSBox 中运行 `MUL9CHK`：

```text
C:\>MUL9CHK
x y
1 1 error
2 3 error
4 5 error
6 6 error
8 8 error
accomplish!
```

逐项核对：

| 位置 (row, col) | 表中值 | 正确值 `row*col` | 结果 |
|---|---:|---:|---|
| (1,1) | 7 | 1 | error |
| (2,3) | 7 | 6 | error |
| (4,5) | 7 | 20 | error |
| (6,6) | 7 | 36 | error |
| (8,8) | 7 | 64 | error |

其余 76 项全部正确。

### 关于题面示例输出的说明

题面示例输出是：

```text
1 1 error
2 3 error
4 5 error
5 6 error
6 8 error
```

但按题面**文字数据**逐项计算，错误位置应为 `(6,6)` 和 `(8,8)`，不是 `(5,6)` 和 `(6,8)`。这两组输出对应的是“7 的不同摆放位置”：

- 题面数据：`7` 出现在 `(1,1)、(2,3)、(4,5)、(6,6)、(8,8)`；
- 示例输出反推：`7` 应出现在 `(1,1)、(2,3)、(4,5)、(5,6)、(6,8)`。

也就是说，题面的数据段与示例输出很可能是从两份略有差异的表格中摘出来的。**程序逻辑不依赖错误位置**：它按 `row*col` 现场计算期望值，表中哪里有错就报哪里。默认使用题面文字数据；若要与示例输出逐行一致，只需把数据改成：

```asm
; 第 5 行第 6 个改为 7，第 6 行第 8 个改为 7
; 同时把第 6 行第 6 个改回 36、第 8 行第 8 个改回 64
db 5,10,15,20,25, 7,35,40,45
db 6,12,18,24,30,36,42, 7,54
```

## 三、汇编实现

### 3.1 整体结构

程序分为三个过程：

| 过程 | 作用 | 入口保存 | 出口恢复 |
|------|------|----------|----------|
| `check_table` | 双重循环检查 81 个元素，打印错误位置 | `AX/BX/CX/DX/SI` | 逆序 `POP` |
| `print_char` | 输出 `DL` 中的一个字符 | `AX/DX` | 逆序 `POP` |
| `print_string` | 输出 `DX` 指向的 `$` 结尾字符串 | `AX/DX` | 逆序 `POP` |

主过程只负责初始化 `DS`、输出表头、调用 `check_table`、输出 `accomplish!`、返回 DOS。

### 3.2 双重循环与下标计算

外层 `BX = row`（1..9），内层 `CX = col`（1..9）：

```asm
mov bx,1                ; row = 1
row_loop:
        mov cx,1        ; col = 1
col_loop:
        ...
        inc cx
        cmp cx,9
        jle col_loop
        inc bx
        cmp bx,9
        jle row_loop
```

对每个 `(row, col)`：

1. 用 `MUL` 算期望值：

```asm
mov ax,bx
mul cx                  ; DX:AX = row * col
push ax                 ; 保存 expected
```

2. 算行优先下标：

```asm
mov si,bx
dec si                  ; SI = row - 1
mov ax,si
mov dx,9
mul dx                  ; AX = (row-1)*9
mov si,ax
add si,cx
dec si                  ; SI = (row-1)*9 + (col-1)
```

3. 取表中实际值并比较：

```asm
mov al,table[si]        ; 数据段寻址：DS:[SI]
mov ah,0
pop dx                  ; DX = expected
cmp ax,dx
je  next_item
```

4. 不相等则输出 `row col error`：

```asm
mov dl,bl
add dl,'0'
call print_char
mov dl,' '
call print_char
mov dl,cl
add dl,'0'
call print_char
lea dx,errmsg
call print_string
```

### 3.3 过程调用与寄存器保护

`check_table` 内部要用 `AX` 做乘法和取值、`DX` 保存期望值、`SI` 做下标，而主过程/外层循环正用 `BX` 存行号、`CX` 存列号。因此过程入口把用到的寄存器全部压栈：

```asm
check_table proc
        push ax
        push bx
        push cx
        push dx
        push si
        ...
        pop si
        pop dx
        pop cx
        pop bx
        pop ax
        ret
check_table endp
```

`print_char` 也不能只保存 `DX`：`INT 21H` 的 `02H` 功能要求功能号放在 `AH`，会覆盖 `AX` 的高字节，所以 `AX` 也要保存。`print_string` 同理，`09H` 功能要修改 `AH`。

### 3.4 数据段寻址方式

本题涉及三种典型寻址，正好对应三种数据位置：

| 位置 | 写法 | 实际地址 |
|------|------|----------|
| 汇编版 `table` | `mov al,table[si]` | `DS:[SI + offset table]` |
| C 全局 `table` | `mov al,DGROUP:_table[bx+di]` | `DS:[BX+DI + offset _table]` |
| C 局部 `table` | `mov al,[bx]`（`BX = BP-82+i*9+j`） | `SS:[BX]` |

汇编版把 `table` 直接放在 `data` 段，`DS` 初始化后即可用 `table[si]` 访问；这就是最直接的“数据段寻址”。

### 3.5 完整汇编源码

完整源码见 [`src/06_mul9_check/mul9chk.asm`](../../src/06_mul9_check/mul9chk.asm)，核心代码如下：

```asm
data segment
table   db 7,2,3,4,5,6,7,8,9
        db 2,4,7,8,10,12,14,16,18
        db 3,6,9,12,15,18,21,24,27
        db 4,8,12,16,7,24,28,32,36
        db 5,10,15,20,25,30,35,40,45
        db 6,12,18,24,30,7,42,48,54
        db 7,14,21,28,35,42,49,56,63
        db 8,16,24,32,40,48,56,7,72
        db 9,18,27,36,45,54,63,72,81

header  db 'x y',0dh,0ah,'$'
errmsg  db ' error',0dh,0ah,'$'
done    db 0dh,0ah,'accomplish!',0dh,0ah,'$'
data ends

code segment
        assume cs:code, ds:data, ss:stack

start:
        mov ax,data
        mov ds,ax

        lea dx,header
        call print_string

        call check_table

        lea dx,done
        call print_string

        mov ax,4c00h
        int 21h

check_table proc
        push ax
        push bx
        push cx
        push dx
        push si

        mov bx,1
row_loop:
        mov cx,1
col_loop:
        mov ax,bx
        mul cx
        push ax

        mov si,bx
        dec si
        mov ax,si
        mov dx,9
        mul dx
        mov si,ax
        add si,cx
        dec si

        mov al,table[si]
        mov ah,0

        pop dx
        cmp ax,dx
        je  next_item

        mov dl,bl
        add dl,'0'
        call print_char

        mov dl,' '
        call print_char

        mov dl,cl
        add dl,'0'
        call print_char

        lea dx,errmsg
        call print_string

next_item:
        inc cx
        cmp cx,9
        jle col_loop

        inc bx
        cmp bx,9
        jle row_loop

        pop si
        pop dx
        pop cx
        pop bx
        pop ax
        ret
check_table endp
```

## 四、C 语言实现

### 4.1 全局数组版本（`mul9g.c`）

```c
#include <stdio.h>

/* 全局数据：table 放在 _DATA 段，具有静态生存期 */
unsigned char table[9][9] = {
    {7, 2, 3, 4, 5, 6, 7, 8, 9},
    {2, 4, 7, 8,10,12,14,16,18},
    {3, 6, 9,12,15,18,21,24,27},
    {4, 8,12,16, 7,24,28,32,36},
    {5,10,15,20,25,30,35,40,45},
    {6,12,18,24,30, 7,42,48,54},
    {7,14,21,28,35,42,49,56,63},
    {8,16,24,32,40,48,56, 7,72},
    {9,18,27,36,45,54,63,72,81}
};

int main(void)
{
    int i, j;

    printf("x y\n");

    for (i = 0; i < 9; i++) {
        for (j = 0; j < 9; j++) {
            if (table[i][j] != (i + 1) * (j + 1)) {
                printf("%d %d error\n", i + 1, j + 1);
            }
        }
    }

    printf("accomplish!\n");
    return 0;
}
```

### 4.2 局部数组版本（`mul9l.c`）

与全局版的唯一区别是把 `table` 的定义移进 `main`：

```c
int main(void)
{
    /* 局部数据：table 放在栈上，函数返回后失效 */
    unsigned char table[9][9] = { ... };
    int i, j;
    ...
}
```

### 4.3 编译与运行

```dos

TCC -IC:\TURBOC3\INCLUDE -LC:\TURBOC3\LIB -ms MUL9L.C

```

### 5.1 全局数组：直接寻址 `_DATA`

`_main` 的关键片段：

```asm
; if (table[i][j] != (i + 1) * (j + 1))
        mov     ax,si           ; AX = i
        mov     dx,9
        imul    dx              ; DX:AX = i * 9
        mov     bx,ax           ; BX = i * 9
        mov     al,byte ptr DGROUP:_table[bx+di]
                                ; ★全局数组：DS:[BX+DI+_table]
        mov     ah,0
        push    ax

        mov     ax,si
        inc     ax              ; i+1
        mov     dx,di
        inc     dx              ; j+1
        imul    dx              ; 期望值
        pop     dx              ; 实际值
        cmp     dx,ax
        je      short @1@142
```

对应的数据段：

```asm
_DATA   segment word public 'DATA'
_table  label byte
        db      7,2,3,4,5,6,7,8,9
        ...
_DATA   ends
        public  _table
```

**特点**：

- `table` 在编译/链接时就写入可执行文件的 `_DATA` 段，程序启动时由 DOS 装入；
- 不需要任何“初始化代码”，`main` 直接访问；
- 访问用 `DS` 段 + `DGROUP:_table` 偏移；
- `_table` 是 `public` 符号，其他模块也可以引用（外部链接）；
- 代码更短，`MUL9G.EXE` 为 6624 字节。

### 5.2 局部数组：栈上分配 + 运行时拷贝

`_main` 的关键片段：

```asm
_main   proc near
        push    bp
        mov     bp,sp
        sub     sp,82           ; ★在栈上分配 82 字节
        push    si
        push    di

; unsigned char table[9][9] = { ... };
        lea     ax,word ptr [bp-82]   ; 目标：栈上的 table
        push    ss
        push    ax
        mov     ax,offset DGROUP:d@w+0; 源：_DATA 中的隐藏模板
        push    ds
        push    ax
        mov     cx,81
        call    near ptr N_SCOPY@     ; ★运行时拷贝 81 字节
```

访问时：

```asm
        mov     ax,si
        mov     dx,9
        imul    dx              ; i * 9
        add     ax,di           ; i*9 + j
        lea     dx,word ptr [bp-82]   ; ★栈上基址
        add     ax,dx
        mov     bx,ax
        mov     al,byte ptr [bx]      ; SS:[BX]
```

函数返回前：

```asm
        mov     sp,bp           ; ★释放 82 字节局部区
        pop     bp
        ret
```

对应的数据段中仍有一个“隐藏模板”：

```asm
_DATA   segment word public 'DATA'
d@      label byte
d@w     label word
        db      7,2,3,4,5,6,7,8,9
        ...
_DATA   ends
```

**特点**：

- `table` 的**存储空间**在栈上（`SUB SP,82`），函数返回后自动失效；
- 初始化数据仍放在 `_DATA` 段的隐藏模板里，进入函数时用 `N_SCOPY@` 拷贝 81 字节到栈；
- 访问用 `SS` 段 + `BP` 偏移，而不是 `DS`；
- `table` 不是全局符号，其他函数/模块看不到；
- 代码更长（多出分配、拷贝、释放），`MUL9L.EXE` 为 6688 字节。

### 5.3 全局 vs 局部：对照表

| 对比项 | 全局 `table` | 局部 `table` |
|--------|--------------|--------------|
| 存储位置 | `_DATA` 段 | 栈（`SS`） |
| 生存期 | 程序运行全程 | 函数调用期间 |
| 初始化时机 | 链接时写入可执行文件，加载即有效 | 函数进入时从隐藏模板拷贝 |
| 访问方式 | `DS:[_table + i*9 + j]` | `SS:[BP-82 + i*9 + j]` |
| 符号可见性 | `public _table`，可跨模块 | 仅函数内部可见 |
| 运行时开销 | 无初始化代码 | `SUB SP,82` + `N_SCOPY@` + `MOV SP,BP` |
| 可重入/递归 | 多份调用共享同一数组，需小心 | 每次调用都有独立副本，天然可重入 |
| 栈空间 | 不占栈 | 占 82 字节栈空间 |

这也解释了为什么“把数据定义成全局还是局部”会影响反汇编：**全局数组的初始化是“静态”的，局部数组的初始化是“运行时”的**。编译器必须为局部数组生成一段拷贝代码，并在栈帧中预留空间。

### 5.4 与汇编版的对照

| 项目 | 汇编版 | C 全局版 | C 局部版 |
|------|--------|----------|----------|
| 数组位置 | `data` 段 | `_DATA` 段 | 栈 |
| 下标计算 | `(row-1)*9+(col-1)` | `i*9+j` | `i*9+j` |
| 乘法 | `MUL`（无符号） | `IMUL`（有符号） | `IMUL` |
| 循环变量 | `BX/CX` | `SI/DI` | `SI/DI` |
| 寄存器保护 | 手写 `PUSH/POP` | 编译器 `PUSH SI/DI` | 编译器 `PUSH SI/DI` |
| 输出 | `INT 21H` | `printf` | `printf` |

C 编译器把 `i` 放在 `SI`、`j` 放在 `DI`，因为它们是调用者保存寄存器；函数入口 `PUSH SI/DI`、返回前 `POP DI/SI`，和我们汇编版手写保护 `BX/CX` 是同一个道理。

## 七、小结

1. **纠错的核心是“现场计算期望值”**：不把正确答案写死，而是用 `row*col` 生成期望值，再与表中值比较，这样换一张表也能用。
2. **双重循环负责遍历 81 个位置**：外层行、内层列；行优先下标 `(row-1)*9+(col-1)` 是二维数组在内存中的展开方式。
3. **过程调用必须保护现场**：`check_table` 用到的 `AX/BX/CX/DX/SI` 全部 `PUSH`，返回前逆序 `POP`；`print_char/print_string` 也要保存 `AX`，因为 `INT 21H` 会改 `AH`。
4. **全局与局部的差别在反汇编里非常直观**：全局数组是 `_DATA` 段里的静态数据，直接 `DS:[_table+...]` 访问；局部数组是栈上的运行时副本，需要 `SUB SP`、`N_SCOPY@` 拷贝和 `[BP-...]` 访问。
5. **题面数据与示例输出存在不一致**：按题面数据实际错误位置是 `(6,6)`、`(8,8)`；程序逻辑正确，若要与示例输出一致，只需按第二节调整表中 7 的位置。
