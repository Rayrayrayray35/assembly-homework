# 汇编语言 作业 · 求和（1+2+…+100 = 5050，并推广到 1+2+…+n）

> 已在 16 位 DOS 环境（DOSBox 0.74-3 + MASM 5.10/LINK，C 部分用 Turbo C++ 3.0）中**实测通过**。
> 工作目录：`D:\myassembly`（DOSBox 里挂载为 `C:`）。

**题目要求**

1. 基本要求：求 `1+2+…+100`，并把结果 `5050` 打印到屏幕（`D:\>sum5050`）。
   **注意结果的数据范围与进制转换**——`5050 > 255`，已超出一个字节。
   - (1) 分别尝试把结果放在**寄存器**、**数据段**、**栈**中；
   - (2) 用户输入 `1~100` 内的任意数 `n`，求 `1+2+…+n` 并输出十进制结果
        （查找 INT 21H 功能表，用其输入功能调用）；
   - (3) 用 **C 语言**实现后，察看反汇编代码并加注释。

---

## 一、结果的三种存放位置（基本要求）

三种写法只在“**累加和保存在哪里**”上不同，其余（循环、显示）完全一样：

| 程序 | 累加和存放位置 | 关键指令 |
|---|---|---|
| `sum1.asm` | **寄存器** `AX` | `ADD AX,BX` |
| `sum2.asm` | **数据段**字变量 `SUM`（`DW 0`） | `MOV AX,SUM` / `ADD AX,BX` / `MOV SUM,AX` |
| `sum3.asm` | **栈**（用 BP 在栈上开一个字 `[BP-2]`） | `SUB SP,2` / `MOV AX,[BP-2]` … |

### 1.1 结果放在寄存器中（`sum1.asm`）

```asm
        .MODEL SMALL
        .STACK 100H
        .DATA
MSG     DB  '1+2+...+100 = $'
        .CODE
START:  MOV AX,@DATA
        MOV DS,AX

        LEA DX,MSG          ; 先显示提示(它会修改 AH)
        MOV AH,09H
        INT 21H

        XOR AX,AX           ; ★累加器 = 寄存器 AX
        MOV CX,100          ; 循环 100 次
        MOV BX,1            ; 加数 1,2,...,100
SUMLP:  ADD AX,BX           ; AX = AX + 加数
        INC BX
        LOOP SUMLP

        CALL PUTDEC         ; 输出 AX 的十进制
        CALL CRLF
        MOV AX,4C00H
        INT 21H
```

### 1.2 结果放在数据段中（`sum2.asm`）

```asm
        .DATA
SUM     DW  0               ; ★结果变量, 放在数据段
MSG     DB  '1+2+...+100 = $'
        .CODE
START:  MOV AX,@DATA
        MOV DS,AX
        LEA DX,MSG
        MOV AH,09H
        INT 21H

        MOV SUM,0
        MOV CX,100
        MOV BX,1
SUMLP:  MOV AX,SUM          ; 从数据段取出当前和
        ADD AX,BX
        MOV SUM,AX          ; 写回数据段
        INC BX
        LOOP SUMLP

        MOV AX,SUM          ; 取最终结果
        CALL PUTDEC
        CALL CRLF
        MOV AX,4C00H
        INT 21H
```

### 1.3 结果放在栈中（`sum3.asm`）

```asm
        .CODE
START:  MOV AX,@DATA
        MOV DS,AX
        LEA DX,MSG
        MOV AH,09H
        INT 21H

        MOV BP,SP               ; BP 指向当前栈顶
        SUB SP,2                ; ★在栈上开出一个字, 当作“栈变量”
        MOV WORD PTR [BP-2],0   ; 初值 0

        MOV CX,100
        MOV BX,1
SUMLP:  MOV AX,[BP-2]           ; 从栈中取出当前和
        ADD AX,BX
        MOV [BP-2],AX           ; 写回栈中
        INC BX
        LOOP SUMLP

        MOV AX,[BP-2]           ; 取最终结果
        ADD SP,2                ; 释放栈空间
        CALL PUTDEC
        CALL CRLF
        MOV AX,4C00H
        INT 21H
```

`PUTDEC`/`CRLF` 两个子程序三个程序共用（见下）。

### 1.4 十进制输出子程序 `PUTDEC`（三处共用）

```asm
PUTDEC  PROC
        XOR CX,CX
        MOV BX,10
PD_LOOP:
        XOR DX,DX
        DIV BX              ; DX:AX ÷ 10 -> 商 AX, 余数 DX
        PUSH DX             ; 余数(当前最低位)入栈
        INC CX
        TEST AX,AX
        JNZ PD_LOOP
PD_OUT: POP DX
        ADD DL,'0'
        MOV AH,02H          ; 功能 2: 显示单个字符
        INT 21H
        LOOP PD_OUT
        RET
PUTDEC  ENDP
```

### 1.5 运行结果

```
D:\>sum1                D:\>sum2                D:\>sum3
1+2+...+100 = 5050      1+2+...+100 = 5050      1+2+...+100 = 5050
```

三者输出完全一致（见 `OUT_SUM1.TXT` / `OUT_SUM2.TXT` / `OUT_SUM3.TXT`）。

## 二、用户输入 n 的版本（`sumn.asm`）

要求“用户输入 1~100 内任意数 n，输出十进制结果”，查 INT 21H 功能表可用的输入功能：

| 功能号 | 作用 |
|---|---|
| `AH=01H` | 从键盘读**一个字符**（带回显） |
| `AH=0AH` | **缓冲输入**：读入一整行到缓冲区（带回显）★本题用 |
| `AH=07H`/`08H` | 读一个字符（不回显） |

用 `0AH` 读入整行后，再逐字符把“数字字符”转成数值：`值 = 值×10 + 位`。

```asm
        .DATA
MSG1    DB  'Please input n (1~100):',0DH,0AH,'$'
MSG2    DB  '1+2+...+n = $'
BUF     DB  5               ; [0] 最大字符数
        DB  0               ; [1] 实际字符数
        DB  5 DUP(0)        ; [2..] 字符内容
        .CODE
START:  MOV AX,@DATA
        MOV DS,AX

        LEA DX,MSG1         ; 提示
        MOV AH,09H
        INT 21H
        CALL READLINE       ; 功能 0AH 读入 n
        CALL DEC2VAL        ; 字符串 -> 数值, 结果在 BX

        MOV CX,BX           ; CX = n
        LEA DX,MSG2
        MOV AH,09H
        INT 21H
        XOR AX,AX           ; 累加和
        JCXZ DONE           ; n=0 则结果为 0
        MOV SI,1
SUMLP:  ADD AX,SI
        INC SI
        LOOP SUMLP
DONE:   CALL PUTDEC
        CALL CRLF
        MOV AX,4C00H
        INT 21H
```

其中 `DEC2VAL`（字符串→数值）与 `READLINE`（读一行）与“进制转换”作业里的写法一致。

**运行结果**（输入 `100`）：

```
D:\>sumn
Please input n (1~100):
100
1+2+...+n = 5050
```

## 三、C 语言实现 + 反汇编注释

### 3.1 C 源码（`sum.c`）

```c
#include <stdio.h>

/* 求 1+2+...+100, 输出结果 5050 */
int main(void)
{
    int i;
    int sum = 0;                 /* 累加和, 用 16 位 int(结果 5050 超过 255) */

    for (i = 1; i <= 100; i++)   /* i = 1,2,...,100 */
        sum += i;                /* sum = sum + i */

    printf("%d\n", sum);         /* 输出 5050 */
    return 0;
}
```

编译（Turbo C++ 3.0，16 位 small 模型）：

```
TCC -IC:\TURBOC3\INCLUDE -LC:\TURBOC3\LIB -ms SUM.C      ; 生成 SUM.EXE
TCC -IC:\TURBOC3\INCLUDE -LC:\TURBOC3\LIB -ms -S SUM.C   ; 生成 SUM.ASM(反汇编)
```

运行结果：`5050`。

### 3.2 Turbo C 生成的汇编（`SUM.ASM`，加注释）

> 下面是 `TCC -S` 的输出（去掉了 `?debug` 等调试伪指令），逐条加中文注释。

```asm
DGROUP  group   _DATA,_BSS
        assume  cs:_TEXT, ds:DGROUP
_TEXT   segment byte public 'CODE'      ; 代码段
_DATA   segment word public 'DATA'
_BSS    segment word public 'BSS'

; ===================== int main(void) =====================
_main   proc    near
        push    bp                      ; 保存调用者的帧指针
        mov     bp,sp                   ; 建立本函数栈帧
        push    si                      ; 保存 si(用来放 i)
        push    di                      ; 保存 di(用来放 sum)

; ---- int sum = 0; ----
        xor     di,di                   ; di = 0  → sum 用寄存器 DI 保存

; ---- for (i = 1; i <= 100; i++) ----
        mov     si,1                    ; si = 1  → i 用寄存器 SI 保存
        jmp     short @1@114            ; 先跳到循环条件判断处
@1@58:                                  ; <— 循环体入口
; ---- sum += i; ----
        add     di,si                   ; sum = sum + i  (di = di + si)
        inc     si                      ; i++
@1@114:
        cmp     si,100                  ; 比较 i 与 100
        jle     short @1@58            ; i <= 100 则继续循环(有符号小于等于)

; ---- printf("%d\n", sum); ----
        push    di                      ; 实参 2: sum
        mov     ax,offset DGROUP:s@     ; 实参 1: 格式串地址
        push    ax
        call    near ptr _printf        ; 调用库函数 printf
        pop     cx                      ; 平衡栈(弹掉两个参数)
        pop     cx

; ---- return 0; ----
        xor     ax,ax                   ; 返回值 0 放进 AX
        jmp     short @1@170
@1@170:
; ---- 函数收尾: 恢复寄存器、返回 ----
        pop     di                      ; 恢复 di
        pop     si                      ; 恢复 si
        pop     bp
        ret
_main   endp

_DATA   segment word public 'DATA'
s@      label   byte
        db      '%d'                    ; 格式串 = "%d\n"
        db      10
        db      0
_DATA   ends
        public  _main
        extrn   _printf:near
        end
```

### 3.3 C 与汇编的对应

| C 语言 | 对应汇编 |
|---|---|
| 函数进入 | `push bp` / `mov bp,sp` / `push si` / `push di` |
| `int sum = 0` | `xor di,di`（sum 放在寄存器 **DI**） |
| `i = 1` | `mov si,1`（i 放在寄存器 **SI**） |
| `i <= 100` | `cmp si,100` + `jle @1@58` |
| `sum += i` | `add di,si` |
| `i++` | `inc si` |
| `printf(...)` | 压入实参 → `call _printf` → `pop cx` 平衡栈 |
| `return 0` | `xor ax,ax`（AX=返回值） |
| 函数返回 | `pop di/si/bp` + `ret` |

**要点**：编译器把两个小变量 `i`、`sum` 都**放进寄存器**（SI/DI）而不是内存，
所以循环又快又短；这与手写汇编里“把累加和放进寄存器”（`sum1.asm`）本质相同。
另外可见，**C 语言里的 `printf` 是库函数调用**；而手写汇编里“输出十进制”得自己
用 `DIV 10` 取余逐位拼字符（`PUTDEC`）——这正是“高级语言一行，汇编一大段”的差别。

## 四、关键点与注意事项

**1. 结果的数据范围（题目特意提醒）**

`1+2+…+100 = 5050`，`5050 = 13BAH`。
- 它 **> 255**，用一个字节（8 位寄存器如 `AL`、`DB`）会**溢出**，必须用 **16 位**：
  寄存器用 `AX`、内存用 `DW`（字）。
- 若继续加大 n，则要注意 16 位最多到 `65535`；`1+…+n ≤ 65535` 时 n ≤ 361。
  再大就需要 32 位（用 `DX:AX` 或 `MUL`/`DIV` 配合）。

**2. 结果的进制转换**

- **输出十进制**：反复 `DIV 10` 取余，余数是“个/十/百…”位，逆序输出（见 `PUTDEC`）。
- 若想输出**十六进制**，把基数换成 16 即可：`DIV 16` 取余，`0~9` → `'0'+`，
  `10~15` → `'A'+(余数-10)`。
- 本题 `5050` 的十六进制是 `13BAH`，可作对照验证。

**3. ★踩过的坑：`INT 21H` 功能 `09H` 会破坏 `AH`**

最初把结果算在 `AX` 后，接着执行 `LEA DX,MSG / MOV AH,09H / INT 21H` 显示提示，
结果 `MOV AH,09H` 把 `AX` 的高字节从 `13H` 改成了 `09H`，`5050`(`13BAH`)
被读成了 `09BAH = 2490`，屏幕上就打印出 `2490`。
**解决**：先显示提示字符串，**再**做累加、输出结果；或输出前用 `PUSH/POP` 保护结果。
这也是本题“注意结果数据表示范围”背后常见的陷阱。

**4. 循环写法**

`MOV CX,100` + `LOOP`（即 `DEC CX` + `JNZ`）即可；只有一个计数器，无需保存 CX。

## 六、小结

- 同一段“求和 + 输出”逻辑，把累加和放在**寄存器 / 数据段 / 栈**里，代码结构几乎一样，
  区别只在访问方式；这也说明“变量放在哪里”是汇编里要人来决定的（C 由编译器安排寄存器/栈）。
- 结果是 `5050`，**超过了 8 位**，必须用 16 位存放与运算；输出十进制要用 16 位除法 `DX:AX ÷ 10`。
- 用 `INT 21H` 的 `09H/0AH/02H` 分别完成“显示提示、读入一行、显示字符”。
- 特别注意 `09H` 会改 `AH`，会破坏放在 `AX` 里的结果——先打印提示、后运算即可避开。
