# 汇编语言 作业1 · 搭建环境 + Hello World 两种运行方式

> 环境已在本机搭好并**实测通过**：常规方式（masm→link→exe）与直接写内存方式（DEBUG 手工写码）都跑出了 `Hello world!`。

---

## 一、实验环境

64 位 Windows **没有 16 位 DOS 子系统**，不能直接运行 16 位的汇编工具和程序，所以用 **DOSBox** 模拟出 DOS 环境，再放进一整套 16 位工具。

| 组件 | 版本 | 位置 |
|---|---|---|
| DOSBox | 0.74-3 | `C:\Program Files (x86)\DOSBox-0.74-3\` |
| MASM（16 位汇编器） | Microsoft Macro Assembler 5.10 → `MASM.EXE` | `D:\myassembly\` |
| LINK（16 位连接器） | `LINK.EXE` | `D:\myassembly\` |
| DEBUG（16 位调试器） | `DEBUG.EXE` | `D:\myassembly\` |
| EXE2BIN（选配） | `EXE2BIN.EXE` | `D:\myassembly\` |

**DOSBox 配置（一劳永逸）**：编辑 `%LOCALAPPDATA%\DOSBox\dosbox-0.74-3.conf`，在 `[autoexec]` 段末尾加上两行，则每次启动 DOSBox 自动挂载工作目录：

```
mount c d:\myassembly
c:
```

（此后 DOSBox 里 `C:` 就对应真实的 `D:\myassembly`，直接 `MASM`、`LINK`、`DEBUG`、`HELLO` 即可用。）

## 二、程序基本结构（hello.asm）

```asm
.model small                 ; 小内存模型：1 个代码段 + 1 个数据段，各 ≤64KB
.data                        ; 数据段
Hello DB 'Hello world!',0dh,0ah,'$'   ; 以 '$' 结尾的字符串（0dh,0ah = 回车换行）
.code                        ; 代码段
START:  MOV AX,@DATA         ; @DATA = 数据段的段地址（由 MASM/LINK 填写）
        MOV DS,AX            ; 段寄存器不能直接赋立即数，须经 AX 中转
        LEA DX,Hello         ; 取 Hello 的偏移地址（等价写法 MOV DX,OFFSET Hello）
        MOV AH,9             ; DOS 功能调用号 9：显示以 '$' 结尾的字符串
        INT 21H              ; 调 DOS
        MOV AX,4C00H         ; 功能号 4CH：带返回码 00 正常结束程序
        INT 21H
END START                    ; END 后的 START 指定程序入口
```

**结构要点**

- `.model small` 声明**内存模型**；`small` = 单代码段 + 单数据段。
- 段：`.data` → `_DATA`（数据段），`.code` → `_TEXT`（代码段），由 DGROUP 组织。段概念是 8086 实模式的核心：地址 = 段地址 : 偏移地址。
- `END START` 把入口标号 START 写进 EXE 文件头（即初始 CS:IP）。
- 程序用 `INT 21H / AH=4CH` 返回 DOS（不是像 .COM 那样用 RET 返回）。

## 三、两种取偏移地址的方式对比（作业点名要求）

源码一用 `LEA DX,Hello`，源码二用 `MOV DX,OFFSET Hello`。

- **`MOV DX, OFFSET Hello`**：`OFFSET` 是**伪指令**，偏移地址在**汇编期**就计算成常数，直接作为立即数写进指令（机器码形如 `BA 00 00`）。
- **`LEA DX, Hello`**：`LEA` 是**取有效地址指令**（Load Effective Address），在**运行期**由 CPU 计算 `Hello` 的偏移地址（机器码形如 `8D 16 00 00`）。

二者对同一变量结果相同。区别：`OFFSET` 是汇编期常量、更省事；`LEA` 是运行期计算、更通用（可写 `LEA BX,[BX+SI+4]` 这类基址/变址，`OFFSET` 做不到）。

HELLO.LST 里的字节对照（`R` = 连接期重定位）：

```
LEA 版：  8D 16 0000 R   LEA DX,Hello
OFFSET版：BA 0000 R      MOV DX,OFFSET Hello
```

## 四、常规方式运行（汇编 → 连接 → 执行）

在 DOSBox 的 `C:\`（= `D:\myassembly`）下：

```dos
MASM hello.asm,hello.obj,hello.lst,hello.crf;
LINK hello.obj,hello.exe,hello.map;
HELLO
```

输出：

```
Hello world!
```

生成物：`HELLO.OBJ`（目标文件）、`HELLO.EXE`（可执行文件）、`HELLO.LST`（列表文件：地址/机器码/源码对照）、`HELLO.CRF`（交叉引用）、`HELLO.MAP`（映射）。

**HELLO.LST 节选**（体现“源码 ↔ 机器码 ↔ 地址”的对应）：

```
行号 地址   机器码              源码
 3  0000   48 65 6C 6C 6F 20   Hello DB 'Hello world!',0dh,0ah,'$'
 4         77 6F 72 6C 64 21
 5         0D 0A 24
 7  0000   B8 ---- R   START:  MOV AX,@DATA
 8  0003   8E D8               MOV DS,AX
 9  0005   8D 16 0000 R        LEA DX,Hello
10  0009   B4 09               MOV AH,9
11  000B   CD 21               INT 21H
12  000D   B8 4C00             MOV AX,4C00H
13  0010   CD 21               INT 21H
```

- `_DATA` 长 `000F`（'Hello world!' 12 字节 + `0D 0A` + `$` = 15 字节）
- `_TEXT` 长 `0012`（18 字节代码）
- `R` 表示该处地址在**连接期**才最终确定（重定位）。

## 五、直接写内存方式运行（不经汇编器，全部手工）

思路：把**数据**和**机器码**直接写进内存的两个段，设好寄存器后执行——即人肉完成汇编器/连接器的工作。

- 数据段 `DS = 076A`，数据写到 `076A:0`
- 代码段 `CS = 076B`，机器码写到 `076B:0`（17 字节）
- 改寄存器 `DS / CS / IP`，然后运行

**DEBUG 会话（本机实测记录，完整见 DBGLOG.TXT）**

**那 17 个字节机器码逐条含义**

```
B8 6A 07   MOV AX,076A   ; AX ← 数据段段地址
8E D8      MOV DS,AX     ; DS ← 076A
BA 00 00   MOV DX,0000   ; DX ← 字符串偏移 0
B4 09      MOV AH,09     ; 功能号 9
CD 21      INT 21        ; 显示字符串
B8 00 4C   MOV AX,4C00   ; 功能号 4C，返回码 0
CD 21      INT 21        ; 结束程序
```

**与常规方式对比**：常规方式里 `@DATA`、`Hello` 的段地址/偏移由 MASM/LINK 计算并重定位；直接写内存方式则是**自己算 ASCII、自己写出机器码、自己指定段地址与寄存器**，最后 `-g` 执行——这正好把“源程序→机器码→内存→执行”的每一环摊开看清楚了。

## 六、常用寄存器的作用（本作业涉及）

| 寄存器 | 在本程序里的作用 |
|---|---|
| **AX** | 累加器。`AH` 放 DOS 功能号（9=显示字符串，4C=结束程序）；也用 `AX` 中转段地址装入 DS |
| **AH** | AX 的高 8 位，DOS 功能调用号 |
| **AL** | AX 的低 8 位（本例未直接用） |
| **DS** | 数据段寄存器，指向 `.data`（字符串所在段） |
| **DX** | 数据寄存器；`INT 21H/AH=9` 时 **DX = 字符串偏移地址** |
| **CS** | 代码段寄存器，指向 `.code` |
| **IP** | 指令指针；**CS:IP** 指向下一条要执行的指令 |
| **SS:SP** | 堆栈段:栈顶；`INT 21H` 内部与返回 DOS 时用到 |
| **ES** | 附加段（本例未直接用） |

**关键结论**：段寄存器 `DS/CS/SS/ES` **不能直接赋立即数**，必须经通用寄存器中转，例如 `MOV AX,@DATA` → `MOV DS,AX`。

## 七、踩坑与环境说明

- 64 位 Windows 不能直接跑 16 位 `DEBUG/MASM/LINK`；必须经 DOSBox。
- DOSBox 0.74 有一个怪癖：`DEBUG < 脚本文件` 重定向时**只认第一行**，后面会卡死（自动化时会遇到）；**交互式手敲完全正常**。
- 作业里提到 `.crf → .ref` 需用 `CREF.EXE`（本环境暂未包含，需要可再补）。
- 工作目录 `D:\myassembly` 下已备好：工具（MASM/LINK/DEBUG/EXE2BIN）、源码（`hello.asm`、`hello2.asm`）、产物（`HELLO.EXE/.OBJ/.LST/.CRF/.MAP`）、以及运行证据（`OUT_HELL.TXT`、`DBGLOG.TXT`）。
