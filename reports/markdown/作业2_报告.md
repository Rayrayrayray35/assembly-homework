# 汇编语言 作业2 · 打印 ASCII 表（小写字母 a–z，每行 13 个）

> 三种实现均已在 16 位 DOS 环境（DOSBox + MASM/LINK + Turbo C 3.0）中**实测通过**。
> 工作目录：`D:\myassembly`（DOSBox 里挂载为 `C:`）。

统一要求：输出小写字母部分（a–z，共 26 个），**每行 13 个**，即两行：

```
abcdefghijklm
nopqrstuvwxyz
```

---

## 一、用 LOOP 指令实现（ascii1.asm）

```asm
.model small
.data
        dummy DB 0
.code
START:  MOV AX,@DATA
        MOV DS,AX
        MOV CX,2            ; 外层：2 行
        MOV BL,'a'          ; 从 'a'(61H) 开始
OUTER:  PUSH CX             ; ★ 保存外层计数器 CX
        MOV CX,13           ; 内层：每行 13 个
INNER:  MOV DL,BL
        MOV AH,2            ; 功能 2：显示单个字符
        INT 21H
        INC BL              ; 下一个字符
        LOOP INNER          ; CX 自减；CX≠0 则回到 INNER
        MOV DL,0DH          ; 回车
        MOV AH,2
        INT 21H
        MOV DL,0AH          ; 换行
        MOV AH,2
        INT 21H
        POP CX              ; ★ 恢复外层计数器 CX
        LOOP OUTER
        MOV AX,4C00H
        INT 21H
END START
```

**关键点——双重循环里 CX 的保存与恢复**

- `LOOP` 指令固定用 **CX** 做计数器（每执行一次 `CX←CX−1`，`CX≠0` 则跳转）。
- 内、外两层都要用 CX，于是进内层前必须把外层的 CX **压栈保存（PUSH CX）**，
  内层结束后 **出栈恢复（POP CX）**，再 `LOOP OUTER`。否则 CX 被内层改掉，外层循环次数就错了。
- 也可以用另一个寄存器（如 SI）代替 PUSH/POP 保存外层计数（见第二部分）。

**运行结果**

```
D:\>ascii1
abcdefghijklm
nopqrstuvwxyz
```

- 机器码/汇编/地址对照见 `ASCII1.LST`。

## 二、用条件跳转指令实现（ascii2.asm）

不用 `LOOP`，改用 **`DEC` + `CMP` + 条件跳转 `JNZ`** 手动控制循环；外层计数放在 `SI`，从而**无需 PUSH/POP**。

```asm
.model small
.data
        dummy DB 0
.code
START:  MOV AX,@DATA
        MOV DS,AX
        MOV BL,'a'          ; 从 'a' 开始
        MOV SI,2            ; 外层：2 行（用 SI 做外层计数，避开 CX）
OUTER:  MOV CX,13           ; 内层：每行 13 个
INNER:  MOV DL,BL
        MOV AH,2
        INT 21H
        INC BL
        DEC CX              ; CX--
        JNZ INNER           ; ★ 条件跳转：CX≠0 继续内层
        MOV DL,0DH
        MOV AH,2
        INT 21H
        MOV DL,0AH
        MOV AH,2
        INT 21H
        DEC SI              ; SI--
        JNZ OUTER           ; ★ 条件跳转：SI≠0 继续外层
        MOV AX,4C00H
        INT 21H
END START
```

**与 LOOP 版的对比**

| | LOOP 版 | 条件跳转版 |
|---|---|---|
| 循环控制 | `LOOP` 指令（隐含 DEC CX + JNZ） | 显式 `DEC` + `CMP`/`JNZ` |
| 计数器 | 只能用 CX，故外层 CX 需 PUSH/POP 保存 | 可用任意寄存器（此处 SI），无需压栈 |
| 本质 | LOOP = “DEC CX, 若 CX≠0 则跳转”的复合指令 | 把这条复合指令拆开手写 |

**运行结果**：与第一部分一致（`abcdefghijklm` / `nopqrstuvwxyz`）。

## 三、用 C 语言实现 + 反汇编并加注释

### 3.1 C 源码（ascii.c）

```c
#include <stdio.h>

/* 打印 ASCII 表中的小写字母 a..z，每行 13 个 */
int main(void)
{
    int  row, col;      /* 行、列计数 */
    char c = 'a';       /* 当前要输出的字符 */

    for (row = 0; row < 2; row++) {          /* 共 2 行 */
        for (col = 0; col < 13; col++) {     /* 每行 13 个 */
            putchar(c);                      /* 输出一个字符 */
            c++;                             /* 指向下一个字符 */
        }
        putchar('\n');                       /* 每行结束换行 */
    }
    return 0;
}
```

### 3.2 编译环境：Turbo C++ 3.0（16 位 DOS）

```
TCC -IC:\TURBOC3\INCLUDE -LC:\TURBOC3\LIB -ms ASCII.C
```
（`-ms` = small 内存模型；生成 `ASCII.OBJ` → 用 Turbo Link 链接成 `ASCII.EXE`）
运行：

```
D:\>ascii
abcdefghijklm
nopqrstuvwxyz
```

### 3.3 反汇编（`TCC -S ASCII.C` 生成的 16 位汇编，加注释）

> 下面是用 `TCC -S -ms ASCII.C` 得到的编译器汇编（`ASCII.ASM`，去掉了调试伪指令），逐段加中文注释。
> 说明：Turbo C 把 `putchar` **内联**成了“往 stdout 缓冲区写字节”的快路径，缓冲满时才调用库函数 `__fputc`。

```asm
; ---------- 段/组 结构（内存模型 small） ----------
DGROUP  group   _DATA, _BSS
        assume  cs:_TEXT, ds:DGROUP
_TEXT   segment byte public 'CODE'     ; 代码段
_DATA   segment word public 'DATA'     ; 已初始化数据段
_BSS    segment word public 'BSS'      ; 未初始化数据段

; ======================= int main(void) =======================
_main   proc near
        push    bp                     ; 保存上层帧指针
        mov     bp,sp                  ; 建立本函数的栈帧：bp = 当前栈顶
        sub     sp,2                   ; 在栈上给局部变量留 2 字节
        push    si                     ; 保存 si（本函数拿它当 row）
        push    di                     ; 保存 di（本函数拿它当 col）

        mov     byte ptr [bp-1],97     ; c = 'a'  （97 = 0x61 = 'a'）

; ---- for (row = 0; row < 2; row++)  —— row 存在 SI ----
        xor     si,si                  ; row = 0
        jmp     short @1@366           ; 跳去先做条件判断
@1@58:                                 ; <— 外层循环体入口
; ---- for (col = 0; col < 13; col++) —— col 存在 DI ----
        xor     di,di                  ; col = 0
        jmp     short @1@226
@1@86:                                 ; <— 内层循环体入口
; ---- putchar(c) —— 内联成“写输出缓冲区” ----
        inc     word ptr DGROUP:__streams+16    ; stdout 缓冲区写指针 +1
        jge     short @1@142           ; 若已越过缓冲末尾(满) → 走慢路径
        mov     bx,word ptr DGROUP:__streams+26 ; bx = 缓冲区当前写位置
        inc     word ptr DGROUP:__streams+26    ; 写位置再 +1
        mov     al,byte ptr [bp-1]     ; al = c
        mov     byte ptr [bx],al       ; 把 c 写进缓冲区（快速输出）
        mov     ah,0
        jmp     short @1@170
@1@142:                                ; <— 缓冲满：调用库函数 __fputc(stdout, c)
        mov     ax,offset DGROUP:__streams+16
        push    ax                     ; 参数1：FILE*（stdout）
        mov     al,byte ptr [bp-1]
        push    ax                     ; 参数2：字符 c
        call    near ptr __fputc
        pop     cx
        pop     cx                     ; 平衡栈（弹掉两个参数）
@1@170:
; ---- c++; ----
        inc     byte ptr [bp-1]        ; c = c + 1
        inc     di                     ; col++
@1@226:
        cmp     di,13
        jl      short @1@86            ; if (col < 13) 继续内层（条件跳转）
; ---- putchar('\n') —— 同样内联 ----
        inc     word ptr DGROUP:__streams+16
        jge     short @1@310
        mov     bx,word ptr DGROUP:__streams+26
        inc     word ptr DGROUP:__streams+26
        mov     al,10                  ; '\n' = 10
        mov     byte ptr [bx],al
        mov     ah,0
        jmp     short @1@338
@1@310:
        mov     ax,offset DGROUP:__streams+16
        push    ax
        mov     al,10
        push    ax
        call    near ptr __fputc
        pop     cx
        pop     cx
@1@338:
        inc     si                     ; row++
@1@366:
        cmp     si,2
        jl      short @1@58            ; if (row < 2) 继续外层（条件跳转）

; ---- return 0; ----
        xor     ax,ax                  ; 返回值 0 放进 AX

; ---- 收尾：恢复寄存器、撤销栈帧、返回 ----
        pop     di
        pop     si
        mov     sp,bp                  ; 丢弃局部变量区
        pop     bp
        ret
_main   endp
```

### 3.4 从反汇编看 C 与汇编的对应

| C 语言 | 对应汇编 |
|---|---|
| 函数进入 | `push bp` / `mov bp,sp` / `sub sp,N`（建立栈帧、分配局部变量） |
| `char c='a'` | `mov byte ptr [bp-1],97` |
| `int row`（`for` 变量） | 存在寄存器 **SI**（`xor si,si`） |
| `int col`（`for` 变量） | 存在寄存器 **DI**（`xor di,di`） |
| `row < 2` / `col < 13` | `cmp si,2` / `cmp di,13` + `jl …`（有符号小于则跳转） |
| `c++` | `inc byte ptr [bp-1]` |
| `putchar(c)` | 内联：算缓冲区指针 → `mov [bx],al`；满则 `call __fputc` |
| `return 0` | `xor ax,ax`（AX = 返回值） |
| 函数返回 | `pop di/si` / `mov sp,bp` / `pop bp` / `ret` |

**要点**：
- 编译器把 `row`/`col` 这种小循环变量放进**寄存器**（SI/DI）而不是内存，这就是“循环提速”的来源；
  而 `c` 取址/对齐后放在栈上（`[bp-1]`）。
- `putchar` 被**内联展开**成缓冲区写入 + 回退调用，说明库函数调用有开销、编译器会优化。
- 两个 `for` 在汇编里是**完全相同**的“初始化→判断→循环体→步进→判断”结构，
  与手写汇编里的 `LOOP`/`JNZ` 循环一一对应——只不过汇编要人自己安排 CX/SI 等计数器，
  而 C 由编译器负责分配寄存器并保证不冲突。
