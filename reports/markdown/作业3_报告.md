# 汇编语言 作业3 · 进制转换（十六进制 ↔ 十进制）

> 已在 16 位 DOS 环境（DOSBox 0.74-3 + MASM 5.10 / LINK）中**实测通过**。
> 工作目录：`D:\myassembly`（DOSBox 里挂载为 `C:`），程序名 `EXCHANGE`。

**题目要求**

- 基本要求：输入 1~2 位十六进制数，输出对应的十进制数。
- 追加要求：实现十进制 → 十六进制的转换。

**结果显示（题目样例）**

```
D:\>exchange
Please input a Hex number:
ff
The Dec number:
255
```

---

## 一、实现思路

程序 `EXCHANGE` 分成两段，依次完成两个方向：

| 段 | 方向 | 输入 | 输出 |
|---|---|---|---|
| 第一部分（基本要求） | 十六 → 十 | 1~2 位十六进制数（0 ~ FF） | 十进制数（0 ~ 255） |
| 第二部分（追加要求） | 十 → 十六 | 十进制数（0 ~ 255） | 十六进制数（0 ~ FF） |

用到的 DOS 功能调用（INT 21H）：

- `AH=09H`：显示一个以 `$` 结尾的字符串（提示语、结果标签）；
- `AH=0AH`：**缓冲输入**——把一整行读进缓冲区，自动回显；
- `AH=02H`：显示单个字符（输出数字的每一位）。

核心算法：

1. **十六进制字符串 → 数值**：从左到右逐字符处理，
   `值 = 值 × 16 + 当前位`；乘 16 用 4 次 `SHL` 实现。
   字符转数值：`'0'~'9' → 0~9`，`'A'~'F' / 'a'~'f' → 10~15`。
2. **十进制字符串 → 数值**：同理，`值 = 值 × 10 + 当前位`（用 `MUL`）。
3. **输出十进制**：反复 **除以 10 取余**，把各位余数压栈，最后从高位到低位弹出、加 `'0'` 显示。
4. **输出十六进制**：把数值按 **4 位一组**（一个十六进制位）拆开，从高位到低位映射成
   `'0'~'9' / 'A'~'F'` 显示；本题数值 ≤ 255，最多两位，且不输出前导零。

## 二、源码（`exchange.asm`）

```asm
;===========================================================
;  程序名 : EXCHANGE.ASM
;  功能   : 进制转换
;           (1) 基本要求: 输入 1~2 位十六进制数, 输出对应十进制数;
;           (2) 追加要求: 输入十进制数(0~255), 输出对应十六进制数。
;  环境   : MASM 5.10 + LINK  (DOS 16 位 .EXE)
;  日期   : 2026-10-16
;===========================================================
        .MODEL SMALL
        .STACK 100H

;======================= 数据段 =======================
        .DATA
MSG1    DB  'Please input a Hex number:',0DH,0AH,'$'
MSG2    DB  'The Dec number:',0DH,0AH,'$'
MSG3    DB  0DH,0AH,'Please input a Dec number:',0DH,0AH,'$'
MSG4    DB  'The Hex number:',0DH,0AH,'$'
BUF     DB  6                   ; 缓冲区最大字符数
        DB  0                   ; 实际读入字符数(由 0AH 填入)
        DB  6 DUP(0)            ; 字符内容

;======================= 代码段 =======================
        .CODE
START:  MOV AX,@DATA
        MOV DS,AX

;-------- 第一部分: 十六进制 -> 十进制 (基本要求) --------
        LEA DX,MSG1             ; 提示
        MOV AH,09H
        INT 21H
        CALL READLINE           ; 读入一行(带回显)
        CALL HEX2VAL            ; 结果 -> BL
        LEA DX,MSG2
        MOV AH,09H
        INT 21H
        MOV AL,BL
        CALL PUTDEC             ; 输出十进制

;-------- 第二部分: 十进制 -> 十六进制 (追加要求) --------
        LEA DX,MSG3
        MOV AH,09H
        INT 21H
        CALL READLINE
        CALL DEC2VAL            ; 结果 -> BL
        LEA DX,MSG4
        MOV AH,09H
        INT 21H
        MOV AL,BL
        CALL PUTHEX             ; 输出十六进制

        MOV DL,0DH              ; 结尾换行
        MOV AH,02H
        INT 21H
        MOV DL,0AH
        MOV AH,02H
        INT 21H

        MOV AX,4C00H            ; 返回 DOS
        INT 21H

;----------------------------------------------------------
; READLINE: 用 DOS 功能 0AH 读入一行到 BUF, 并补一个回车换行
;----------------------------------------------------------
READLINE PROC
        LEA DX,BUF
        MOV AH,0AH
        INT 21H
        MOV DL,0DH              ; 补回车换行, 使输出另起一行
        MOV AH,02H
        INT 21H
        MOV DL,0AH
        MOV AH,02H
        INT 21H
        RET
READLINE ENDP

;----------------------------------------------------------
; HEXDIG: 把 AL 中的 ASCII 字符转成 0..15
;         合法返回 0..15 且 CF=0, 非法则 CF=1
;----------------------------------------------------------
HEXDIG  PROC
        CMP AL,'0'
        JB  HD_BAD
        CMP AL,'9'
        JBE HD_NUM
        AND AL,0DFH             ; 小写字母转大写
        CMP AL,'A'
        JB  HD_BAD
        CMP AL,'F'
        JA  HD_BAD
        SUB AL,'A'-10           ; 'A' -> 10
        CLC
        RET
HD_NUM: SUB AL,'0'              ; '0'..'9' -> 0..9
        CLC
        RET
HD_BAD: STC
        RET
HEXDIG  ENDP

;----------------------------------------------------------
; HEX2VAL: 把 BUF 中的字符串按十六进制累加, 结果存入 BL
;----------------------------------------------------------
HEX2VAL PROC
        MOV BX,0                ; 累加器
        MOV SI,2                ; BUF 中字符从偏移 2 开始
        XOR CX,CX
        MOV CL,BUF+1            ; 实际读入的字符数
        JCXZ H2V_RET
H2V_LOOP:
        MOV AL,BUF[SI]
        CALL HEXDIG
        JC   H2V_NEXT           ; 非法字符(如回车)跳过
        SHL BX,1                ; BX = BX * 16
        SHL BX,1
        SHL BX,1
        SHL BX,1
        XOR AH,AH
        ADD BX,AX
H2V_NEXT:
        INC SI
        LOOP H2V_LOOP
H2V_RET:
        RET
HEX2VAL ENDP

;----------------------------------------------------------
; DEC2VAL: 把 BUF 中的字符串按十进制累加, 结果存入 BL
;----------------------------------------------------------
DEC2VAL PROC
        MOV BX,0
        MOV SI,2
        XOR CX,CX
        MOV CL,BUF+1
        JCXZ D2V_RET
D2V_LOOP:
        MOV AL,BUF[SI]
        CMP AL,'0'
        JB  D2V_NEXT            ; 非数字字符跳过
        CMP AL,'9'
        JA  D2V_NEXT
        SUB AL,'0'
        XOR AH,AH
        PUSH AX                 ; 保存当前位数字
        MOV AX,BX
        MOV DX,10
        MUL DX                  ; DX:AX = BX * 10
        MOV BX,AX
        POP AX
        ADD BX,AX
D2V_NEXT:
        INC SI
        LOOP D2V_LOOP
D2V_RET:
        RET
DEC2VAL ENDP

;----------------------------------------------------------
; PUTDEC: 把 AL 中的无符号数(0..255)以十进制输出
;----------------------------------------------------------
PUTDEC  PROC
        XOR AH,AH
        XOR CX,CX
        MOV BX,10
PD_LOOP:
        XOR DX,DX
        DIV BX                  ; AX=商, DX=余数
        PUSH DX                 ; 余数压栈
        INC CX
        TEST AX,AX
        JNZ PD_LOOP
PD_PRINT:
        POP DX
        ADD DL,'0'
        MOV AH,02H
        INT 21H
        LOOP PD_PRINT
        RET
PUTDEC  ENDP

;----------------------------------------------------------
; PUTHEX: 把 BL 中的数(0..255)以十六进制输出(无前导零)
;----------------------------------------------------------
PUTHEX  PROC
        MOV AL,BL
        CMP AL,16
        JB  PH_LOW              ; 只有个位
        MOV DL,AL               ; 高 4 位
        MOV CL,4
        SHR DL,CL
        CALL PHDIG
PH_LOW: MOV DL,BL
        AND DL,0FH              ; 低 4 位
        CALL PHDIG
        RET
PUTHEX  ENDP

;----------------------------------------------------------
; PHDIG: 把 DL 中的 0..15 以十六进制字符输出
;----------------------------------------------------------
PHDIG   PROC
        CMP DL,10
        JB  PHD_NUM
        ADD DL,'A'-10
        JMP PHD_OUT
PHD_NUM:
        ADD DL,'0'
PHD_OUT:
        MOV AH,02H
        INT 21H
        RET
PHDIG   ENDP

        END START
```

## 三、关键点说明

**1. 缓冲输入（功能 0AH）的缓冲区格式**

```
BUF  DB 6        ; [0] 最大可输入字符数(不含回车)
     DB 0        ; [1] 实际读入字符数(由 DOS 填入)
     DB 6 DUP(0) ; [2..] 读入的字符内容
```

读入后字符串从 **偏移 2** 开始、长度放在 **偏移 1**。所以 `HEX2VAL`/`DEC2VAL`
都以 `SI=2` 起步、以 `BUF+1` 作为循环次数。功能 0AH 会**自动回显**输入，
所以运行时能看到自己敲的 `ff`。

**2. 十六进制累加（`HEX2VAL`）**

每读一个字符：先判断合法性（`HEXDIG`），合法则 `BX = BX × 16 + 位值`。
乘 16 不用乘法指令，而是连续 4 次 `SHL BX,1`（左移一位等于乘 2），
这比 `MUL` 更快，也是汇编里常见的写法。对 `ff` 来说：
`0×16+15 = 15`，再 `15×16+15 = 255`。

**3. 十进制累加（`DEC2VAL`）**

同理，只不过乘数是 10，用 `MUL` 实现（`DX:AX = AX × 10`）。
处理每一位前先把当前位数字 `PUSH` 保存，因为 `MUL` 会占用 `AX`/`DX`。

**4. 十进制输出（`PUTDEC`）**

数值反复 `DIV 10`：余数是**最低位**，商继续除。由于先得到低位、后得到高位，
所以把余数依次**压栈**，除完后再依次**弹栈**输出，就得到高位在前的正确顺序。

**5. 十六进制输出（`PUTHEX` + `PHDIG`）**

一个十六进制位对应 4 个二进制位。先把数值与 `0FH` 相与取低 4 位，
若数值 ≥ 16 再把高 4 位（`SHR 4` 后）输在前。0~9 加 `'0'`，
10~15 加 `'A'-10` 得到大写字母。数值为 0 时直接输出 `0`，不补前导零。

**6. 全部用子程序（`PROC`/`ENDP` + `CALL`）组织**

输入、转换、显示各自独立成过程，主流程只有顺序调用，结构清晰、便于阅读与调试。

## 六、小结

- 用 `INT 21H` 的 `09H / 0AH / 02H` 三个功能即可完成“显示提示、读入一行、显示结果”的全部人机交互。
- 进制转换的本质是**按权展开**：十六进制乘 16、十进制乘 10，逐位累加；
  而**输出**则是反复取余（除以基数）求得各数位。
- 乘 16 用移位（`SHL`）代替乘法，是汇编中常用的效率技巧。
- 子程序化后主流程一目了然；两个方向的转换共用同一套“取位 → 映射成字符”的思路。
